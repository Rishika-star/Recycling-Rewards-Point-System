# Recycling Rewards Point System

## Project Overview
The Recycling Rewards Point System is a Java-based application
designed to encourage residents to recycle waste materials by
providing reward points based on the quantity of recyclable
materials collected.

## Objectives
- Encourage recycling and responsible waste management.
- Maintain resident and recyclable material records.
- Calculate reward points based on collected materials.
- Allow residents to redeem their earned points.
- Generate recycling and reward reports.

## Key Features
- Resident Registration
- Material Management
- Recycling Collection Records
- Reward Point Calculation
- Reward Redemption
- Report Generation

## Technologies Used
- Java
- Maven
- MySQL (planned)
- JDBC (planned)

## Project Status
Currently in the initial setup and core Java development phase.
